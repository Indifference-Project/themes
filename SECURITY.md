# Security policy

Report vulnerabilities in this fork through [GitHub private vulnerability reporting](https://github.com/yuchen0x1/themes/security/advisories/new). Include the affected version, impact, and a minimal reproduction. Keep credentials and private user data out of the report.

Security fixes target the latest stable fork release. Report upstream issues through [Radix Themes security](https://github.com/radix-ui/themes/security).

For package verification and rollback, see the [release process](./release-process.md).
